# Automatic Street Light System Using LDR Sensor

## Project Overview
The Automatic Street Light System is an electronics project that automatically controls street lights based on the surrounding light intensity using an LDR (Light Dependent Resistor) sensor.

## Objective
To reduce unnecessary electricity consumption by automatically switching street lights ON during darkness and OFF during daylight.

## Components Used
- Arduino Uno
- LDR Sensor
- 10kΩ Resistor
- LED
- 220Ω Resistor
- Breadboard and jumper wires

## Working Principle
The LDR sensor detects the surrounding light intensity and provides an analog signal to the Arduino. Based on a predefined threshold value, the Arduino controls the LED.

- During daylight: LED remains OFF.
- During darkness: LED turns ON.

## Applications
- Automatic street lighting
- Garden lighting
- Smart home lighting
- Energy-saving systems

Arduino IDE, Embedded C/C++ and basic electronics.
